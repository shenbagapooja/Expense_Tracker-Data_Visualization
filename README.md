# 📂Expense Tracker – Data Analysis & Visualization

A beginner-friendly **Python Expense Tracker** that stores expenses using JSON and analyzes the data using Pandas and Matplotlib.

## Features

* Add expenses
* View expenses
* Delete expenses
* Store expense data using JSON
* Calculate total, highest, and lowest expenses
* Analyze expenses using Pandas
* Visualize expenses using Matplotlib
* Category-wise expense analysis
* Expense summary

## Technologies Used

* **Python**
* **JSON** – Data storage
* **Pandas** – Data analysis
* **Matplotlib** – Data visualization

## Expense Details

Each expense contains:

* Name
* Amount
* Category
* Date

## How to Run

1. Install Python.
2. Install the required libraries:

```bash
pip install pandas matplotlib
```

3. Run the Python file:

```bash
python expense_tracker.py
```

4. Follow the menu displayed in the terminal.
